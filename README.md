# بوفه — BOOFEH Market

نمونه یک مارکت‌پلیس مستقل دانشجویی برای فروش مرچ، خدمات خلاق و بلیت رویدادها. این نسخه با React و Vite ساخته شده است.

## امکانات نسخه آزمایشی

- دو بخش مستقل برای محصولات رسمی بوفه و بازار دانشجویی
- ورود نمایشی در دو نقش مشتری و مدیریت
- ثبت آگهی توسط مشتری و ارسال آن به صف بررسی
- تأیید انتشار آگهی‌های دانشجویی توسط مدیریت
- افزودن، ویرایش، حذف و تخفیف‌گذاری محصولات در پنل مدیریت
- دسته‌بندی و جست‌وجوی محصولات و خدمات
- موجودی مستقل برای هر آیتم
- سبد خرید تعاملی و ذخیره وضعیت در مرورگر
- کیف پول «ژتون» و کوپن‌های یک‌بارمصرف
- پرداخت کاملاً شبیه‌سازی‌شده پس از تأیید کاربر
- رابط راست‌به‌چپ و واکنش‌گرا
